# Legacy mobile source (archived)

This folder contains an old, unmaintained client retained only for historical reference.

- It is not the current version of SpeedyWatch.
- It receives no updates, support, releases, or compatibility work.
- It is not offered as an installable download.
- The Android app in the repository root is the main and only maintained version.

If you need a newer version of this legacy client, message the repository owner. It may be possible to provide one, but availability is not guaranteed.
